# WuBuDesk 7-Step Research Program (the "get everything" sweep)

Boss: "seven steps research from that to get even more and get them all and
understand that you want everything." This is the standing research program —
7 domains, each a deep-dive with a written deliverable, so WuBuDesk understands
the WHOLE cohost/AGI stack and can request the right things from the back-room
agents (engine + Colonels). Each step maps to a doc in knowledge/.

## THE 7 STEPS
1. **Persona & cohost craft** → RESEARCH_STEP1_PERSONA.md
   VTuber/overlay design, popup-trigger logic, talking-to-streamer patterns,
   the Reflexion feedback spine. (This session: built wizard overlay + loop.)
2. **Voice & speech** → RESEARCH_STEP2_VOICE.md
   TTS (Kokoro-82M/Chatterbox), STT (Canary-Qwen/Parakeet), lip-sync (15KB
   viseme engine + WebAudio freq analysis), prosody, interruptibility.
3. **Vision & perception** → RESEARCH_STEP3_VISION.md
   Local VLMs (Qwen3.5-9B multimodal fits 8GB), OCR (GLM-OCR), desktop/screen
   understanding, multi-region, the "eyes".
4. **Brain & orchestration** → RESEARCH_STEP4_BRAIN.md
   Local LLM brains, llama-server router swarm, agent memory frameworks
   (Graphiti/Mem0/Letta/Cognee/EverOS), the "40 hands".
5. **The AGI fleet & models** → MODEL_LANDSCAPE_2026.md (done)
   2026 open-weight releases, quants (IQ2_M), what to pull.
6. **Engine & Colonels (back-room paces)** → wubudesk-operations skill + PACE_DEEPSEEK_V4.md
   wubuwizard architecture, WUBUOS kernel, gaps -> requests for designers.
7. **Stream & movie integration** → AGI_MADE_THIS_MOVIE.md (done)
   OBS mechanics (WebSocket 5 control), TikTok clip rollout, host role, public drop.

## PRINCIPLE
- Every step ends in a written doc + a list of concrete requests for the
  back-room agents (the "celebrity on stage yelling at the people in the back").
- Local-first. Open-weight. No cloud dependency where avoidable.
- Reflexion: each step's lessons feed memory/reflections.json.
